# Third-party agent skills

The agent skills in `.agents/skills/` and `.claude/skills/` are copies from
[Vercel's Agent Skills](https://github.com/vercel-labs/agent-skills). The
installed sources and content hashes are recorded in `skills-lock.json`.

The upstream project declares the MIT license in its README. These copies
remain subject to their upstream license and attribution; this notice does not
set a license for DraftForMe's own code.
